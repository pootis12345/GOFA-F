# Stage59: connected independent source confirmation and six-target evaluation

This read-only pipeline follows the already running finite source fits. It
does not restart training, refit fusion, choose another checkpoint or alter the
accepted tensor core. The precision goal remains unproven until all six target
variable-equal raw MAEs are strictly lower than Native and sufficiently trained
official UFG. A completed implementation or green CPU suite is not that result.

## Sequence and scientific boundaries

1. Observe the existing verified source supervisor and UFG process handles.
   Both source fits must finish, their unique checkpoints/fusion must be sealed,
   activity workers must be null, and the processes must exit before evaluation.
   A missing/failed handle with incomplete source locks is an implementation
   audit condition, never permission to relaunch training from initial state.
2. Bind the selected depth, expert, source-fitted gate, both official UFG source
   bests, pretrained weights and execution code. The old real7B acceptance binds
   tensor/input and UFG kernels; the later formal source runtime separately binds
   the shared fusion implementation. Their stages are not conflated.
3. Execute the original sealed256source confirmation queries,32per view/shape.
   Native, direct enhanced, frozen fusion and UFG all predict before CPU scoring
   opens the confirmation labels. Report this independent generalization check
   honestly. It does not refit parameters or select a second candidate. No new
   source-performance advancement threshold is silently introduced.
4. After confirmation completion and unchanged deployment certification, prepare
   and seal128new queries for each of the six fixed target datasets. Preserve
   the original Stage21 variable identities and per-variable quotas. Choose new
   legal last20% origins using fixed ID/time seeds and missing-value eligibility;
   same-variable labels cannot overlap the original frozen target list or each
   other. Insufficient capacity stops preparation without substitution.
5. Generate all four groups and only then score once on CPU. No target outcome
   returns to training, text, sampling, global depth, fusion or model selection.

Every prediction worker receives serialized history-only data and task text,
with no future-value or future-mask accessor. Input shards, every Native sample
trajectory, medians and continuous predictions are atomic and content-bound.
Recovery only fills missing records, recreates independent KV, and validates
model/query/input/runtime identities. Completed prediction groups are not
regenerated merely to resume CPU scoring.

## Protected execution and cost

Native retains the accepted official prompt, numeric grammar, BF16 kernel,
fixed-origin scaling and eight independent local-RNG draws. One unconditioned
Native prompt prefill is read-only; each trajectory clones its KV. Its frozen
root hidden state after26or29blocks is also used by the enhanced stream. Auxiliary
nodes execute the same frozen prefix without autoregressive generation.

The numerical expert uses the same optimized Memory tail accepted in training;
there is no new fallback implementation hiding divergence. A new real-weight
proof checks the shared-origin path before predictions: exact historical four
source seed0token replays, both12→12/48→24shapes, independent versus shared
prefix/enhanced outputs, eight exact sampled-token paths per shape, independent
full-prefix versus incremental seed0tokens, unmodified prompt KV and RNG.
CPU FP32 tolerance1e-6 and CUDA BF16 tolerance2e-3 remain fixed. Failure stops the
evaluation for repair with evidence preserved. No optimizer/backprop entry exists.

UFG uses the pinned official width128model, its two locked shape-specific source
checkpoints, and the identical real history roster with disclosed trailing zero
pads up to31roles. CPU execution remains two threads and CUDA disabled. Source
caps/early stopping and the actual UFG learning curves are reported; reaching a
finite cap is not claimed as convergence.

The evaluation uses independent flat outputs under the same project GPU lock:
`stage59-dual-memory-source-confirm-v1` and `stage59-dual-memory-targets-v1`.
`stage59-dual-memory-evaluation-v1` is the CPU coordinator. This is a local
run-bound process, not a restored recurring app heartbeat. New GPU workers use
memory_cap_only admission,40GiBproject/38GiBTorch and10saudits; no idle wait,
wall deadline or activity limit. Partial outputs survive cooperative≤60s exits.
No locked roster is reduced to fit memory.

Evaluation ledgers record only new residency. The final cumulative summary adds
the source ledger, which already includes the mechanism cost, exactly once.
CPU UFG costs are separate. Show measured per-query/trajectory progress and
conditional remaining confirmation/target cost; unknown resource pauses are
excluded, and ETA is unknown before observed throughput.

## Metrics, conclusion and delivery

For each variable, aggregate all valid forecast points in raw units; then average
variables equally. Report MAE, mean per-variable RMSE, MAPE on|y|>1e-5 with valid
coverage, and WAPE with zero-denominator entries null. Include micro alternatives,
per-variable and per-step values and paired improved/tied/degraded counts.
Native language-format and inverse-transform completion are separate from the
continuous expert/fusion outputs. Report historical representable-range exits,
Native endpoint frequency, hard Native fallback and actual real-node coverage.

Use2000paired resamples of fixed graph-local spatial blocks and seven-day time
blocks, seed4259, with a separate time-only interval. A single spatial cluster
does not produce a spurious spatial-confidence interval; small cluster counts
and limited time blocks are disclosed. Do not pool different raw physical units.

The strict target gate is MAE_fusion<MAE_baseline-max(1e-12,1e-9*MAE_baseline)
for both baselines on every dataset. Report Native, enhanced, fusion and UFG
even when rankings differ from the objective. A failed gate leaves the goal
unachieved, without target-driven retraining or selective reporting.

Deliver sealed model/config/text/query/code SHA, source confirmation, full six
target results, parameter counts and actual costs. Disclose single training seed,
old target development exposure, unverifiable backbone pretraining exposure,
coordinate4NNweather/wind proxy graphs, model-derived EngRAD measurements,
UFG shape/padding adaptations, and that fixed-sample wins/intervals alone do not
prove stable general superiority. There are no extra SCADA inputs or target-label
updates in this experiment. Mechanism attribution follows the main prediction
experiment and is not automatically inferred from fusion gains.
