## 能够与不能够得出的结论

1. 在同一官方FP16/提示/滚动/解析路径内，只改采样策略，贪心出现块内恒值，而8采样中位数不恒值。
   该病例支持贪心自回归是重复的重要贡献因素；即使没有Stage19有限数值词表约束，也能出现重复。
   它不证明约束、训练或图模块完全没有影响，更不能将图模型104.227661端点聚集全部归于贪心。
2. 不重复不等于更准：本例8采样MAE8.54反而高于贪心7.78。
   单病例/单种子不能据此决定全局优劣或正式修改选模和解码协议。
3. 发现真实提示格式差异：Stage19少两处空行，本例官方149token、Stage19格式147token。
   此前“官方提示完全一致”的说法不准确；本次空行窄对照的贪心输出相同，因此不能把此病例归因空行。
4. 已有Stage19原生参考与本次官方主测试还同时存在精度、受约束解码、分块和缩放等差异，
   对照它们不能单独估计8采样的影响；上表第二行才是同路径采样策略窄对照。
