# Stage61：先独立训练TSGFM适配专家，再决定是否接入Memory

## 目标与不变范围

用户提出先取得有竞争力的独立零样本图专家，再接入当前双流Memory架构。本阶段先完成一个固定专家的源训练和低成本推进筛查，不代替最终六目标验收。Stage60健康训练不改快照、不重启；本阶段不加载ChatTime、不新增LLM联合训练，不读取目标成绩来选模型。六目标、原生8采样、真实节点和三跳整跳10候选规则均不变。

作者仓库为https://github.com/HamidL/TSGFM，固定提交01356fbe6488105dcaf21e182f9a438254bffe93，正式论文https://dl.ifip.org/db/conf/cnsm/cnsm2025/1571173306.pdf。不要混淆Text-space Graph Foundation Model同名仓库。官方树未含LICENSE；仅私有保存原文件供审计，公共代码是依据论文公式的独立实现，不复制或分发作者源码。代码参考用于确认模型含并行空间/时间注意力、相对时距嵌入、消息合并及GRU更新，不把当前旧GRU专家称为TSGFM。

## 单一适配模型

宽128、一次并行时空消息迭代，保留MLP注意力、相对时距嵌入、合并线性层和GRUCell。每个历史节点时刻独立编码数值和已观测掩码；空间边使用已锁定31上限物理诱导图及已有自环，时间边只由严格更早且有效的历史观测指向较晚历史。空邻域返回零消息，全部缺失辅助节点不发送消息。原论文使用全连接空间图，这里是物理图适配版，不声称严格复现论文成绩。

每节点仅用原L步历史的MinMax，常数尺度取1；历史完整输入，不用目标训练段统计拟合归一化。共享直接多步头读取最后历史状态及四个相对/绝对形状特征，输出最后观测加历史尺度乘残差，统一支持12→12和48→24，无逐集或逐节点身份参数。未把最后层置零从而要求初始输出恒为持久性；最佳更新0如实指未训练的本专家，不混同Stage60已预训练初始化。

## 源数据、训练与恢复

只读复用Stage59源清单及33024条实际节点缓存：四视图各8192训练、两形状合计256开发。PEMS04 flow/speed同一交通来源，另为Boston2017、Penmanshiel2017；训练只有前60%标签，开发为源中间20%，所有采样节点采用相同有效未来槽，不输入未来值或缺失标志。不下载新数据，不扩大历史，不加SCADA。

先CPU两线程实测八个视图×形状的前反向和全部梯度，给出吞吐后才估ETA。CPU禁CUDA；固定seed42、AdamW lr1e-3且wd0（即无衰减Adam更新）、clip1、有效batch16/微1、warmup50、最多10000更新，每250完整开发验证。至少2000更新，0.1%参考连续8次不显著改善则早停；严格最低源分保存最佳。数据池第一步全部启用。沿用原全节点有效槽→节点→查询损失和训练段单位归一化、三领域等权查询循环与源开发选模分数。保存每次完成更新、部分累积梯度、优化器、RNG、游标、验证分片和选择状态；不重置成本，不自动盲重启失败。

## 两级推进与UFG公平性

第一步只做全源专家拟合。复用原官方UFG宽128的两形状源最佳及其同清单源开发记录，逐条验证模型SHA、query、输入SHA、真值/掩码和完整性。原12→12在10000更新上限结束、最佳9000，不称已证明收敛；48→24按早停结束。旧UFG训练成本保留，不把复用预测计为新增训练。

源开发按变量有效点MAE聚合；每视图取专家/UFG误差比，交通两个视图等权几何平均，再三领域等权。只有各领域比值≤1.02且三领域几何平均≤0.99，才推进。该筛查双方都见过相应来源的训练标签，**不是零样本胜出证据**。失败封存，不用目标结果追加调参。

通过后下一阶段才运行严格匹配的留交通/气象/风电外推：两交通视图始终一起留出，TSGFM和UFG均仅在纳入源选模。UFG保持官方结构/宽度/相同历史/全部节点有效标签，使用充分预算；如短形状原上限尚未满足早停，需要预注册续训充分性检查，不能凭原有限预算成绩宣称公平强胜。外推推进门槛同上。在所有外推前不接入LLM、不读取固定六目标标签。

## 接入后的目标仍完整保留

源外推支持后，保留专家原数值路径，以零初始化小接口让专家状态进入专用Memory、Memory经GNN/冻结LLM双向交织后再调制专家，要求接入初态精确重现独立专家。所有真实节点仍共享冻结ChatTime，主六轮/仅候选三轮、源外推选择全局深度；原生流严格图隔离，源交叉拟合训练共享融合器。不能用单纯输出并联冒充完成双向交织目标。

集成后须重新进行源确认、模型/配置锁定及一次目标评价，不能继承独立模型的精度结论。六集变量等权MAE严格低于原生和充分UFG才判精度成功；独立专家、增强流和融合分别报告，不强制排序。既有目标开发暴露继续披露，不将新的起点称全新盲测。未独立跑目标前不宣称专家零样本强于UFG。
