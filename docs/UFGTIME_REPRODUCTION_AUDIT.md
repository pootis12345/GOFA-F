# UFGTime 来源与适配审计

来源：PVLDB 18(9), 3175–3188, 2025，
[论文](https://www.vldb.org/pvldb/vol18/p3175-gao.pdf)、
[官方仓库](https://github.com/WonderHeiYi/UFGTIME)。
固定提交 `61f55135bc2bd6e9b9e5d592009d358015eea681`。
归类为纯图预测范式：频域图及 framelet 消息传递共同处理时序/变量关系；
FFT、趋势分解和输出线性层不等同另接 RNN/Transformer 主干。

## 可复核的代码事实

- 当前运行入口使用 `FreqTimeUFGV2`。
- `conv2_list` 和 `embeddings` 被注册，但有效前向没有使用它们；第二组图卷积前向被注释。
- `main.py` 的训练循环没有每步 `zero_grad`，验证改善时立即调用 test，且没有完整检查点保存/恢复。
- `argument.py` 同一次 add_argument 重复指定 help，不能作为本项目训练入口直接运行。
- 当前实现与论文描述/参数表存在需要披露的版本差异；不能只因源码来自作者就声称复现原论文精度。

官方源码不改写，运行时隔离导入 model/utils。闲置参数仅关闭 requires_grad，不改变有效前向或共有初始化。
使用独立训练器修正梯度清零、测试隔离、调度器/优化器/RNG/游标恢复；这些是训练协议适配。
模型文件 SHA256 `c7229e78ebb136570f783a62d4fd68760d8c36a5b93394a25429b26136de82b1`，
utils SHA256 `3839d247121677327e415695c867c0ee18415e00b93efb121292de15a4950701`。
完整原文件清单位于 C `external/ufgtime/manifest.json`，准备脚本逐项核对来源压缩包及文件哈希。

## 数据与参数口径

论文包含医疗、能源、交通、金融等14数据集，但 Electricity2H、Solar-FL 与本项目版本不同，
没有据此宣称作者在本六集有公开结果，也不把跨领域分别训练等同单检查点零样本预测。
本项目使用原六数据集与配对 L/H，训练段逐节点标准化、自然缺失 mask、70/10/20切分。
主对照关闭 GOFA 额外源时钟，但保留其物理/地理图；UFG 保留自己的频域学习图算法。

复数张量每个元素计两个实数自由度。分别输出 registered_numel、registered_real_dof、
active_real_dof、trainable_real_dof 及闲置参数名称，不按第一次反向是否零梯度判断闲置。
UFG-S 为统一宽度16，UFG-A 仅通过有效前向的线性宽度关系匹配108,930的±10%。
不将闲置分支、固定节点/频率滤波参数或复数口径混入“约21M总参数匹配”结论。
目标匹配是实际可训练自由度；冻结 Bolt 的预训练信息、总参数和计算成本仍不相同。

原作者逐数据集调参配置没有原样照搬：本轮采用统一 Haar/level1/k2/order2/s2、
频域长度max(16,L)、统一有效batch64、两种候选学习率、最多100epoch/patience15。
UFG使用标准化 MSE/RMSprop，GOFA使用原始单位 MAE/AdamW；均按 raw验证MAE选最佳检查点。
这些差异全部保留，结果应称“官方有效模型在本项目协议下的适配”。

## 机制验证状态

现阶段静态检查与原生环境126项 CPU 测试通过（另外10项UFG算子尚待独立环境）；
独立 DGL 环境的算子检查正在准备。
官方前向一致性、复数梯度、批次隔离和真实 CUDA 恢复检查通过前，不启动正式比较。
来源哈希与机制测试只能证明实现来源/运行正确性，不能证明达到原论文精度。
