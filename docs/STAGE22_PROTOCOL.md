# Stage22：源数据共享图幅度门控

固定3500源最佳适配器SHA256 `816d38b577a6664f30dd6e6b6d50986a77b098ce9c4c0b0ffb63d70078b26f15`。
Stage19/20/21旧运行及每小时跟进保持停止。冻结ChatTime和两次图交换，不增加数值预测头、不更新神经参数。

## 单路径门控

所有目标和未见数据集使用同一源训练门控；不输入数据集/节点ID、不拟合目标标签。
生成前根据[t0−L,t0)目标历史和原采样子图选择alpha∈{0,.25,.5,1}，全查询八采样保持同一alpha。
0直接走原生，其余两次交换对全部节点缩放delta；第二次由改变后的第一次状态重算。
原骨干、语言头、BF16、起点尺度、10000有限数值token、单块H≤24和top100/temp1/top_p1采样不变。

特征固定11项：logL/logH、目标缺失率、总体标准差/范围、末四分段减首四分段均值/范围、
有效相邻绝对差均值/范围、邻居数/8、按去自环后B归一权重的绝对相关/有符号相关/重叠/趋势符号一致率。
四分段端点各取floor(L/4)，无有效端点则趋势0，空统计0；尺度范围<10×float64 epsilon时取1。
全缺失、有效历史<8或无外部发送邻居直接选择原生；6节点是合法输入，不用源样本节点数范围作OOD门槛。

唯一多输出DecisionTreeRegressor(max_depth=2,min_samples_leaf=16,criterion=squared_error,random_state=42)。
标签是三种非零幅度的(自由八采样中位数MAE−原生MAE)/官方起点范围；常数范围按官方1。
特征按sklearn float32输入，误差和树值float64；树导出JSON，不依赖pickle。
预测最低增量≤−.01才启用图，并列取较小alpha；否则原生。不搜索系数、特征、树深或阈值。

## 源拟合与两道准入

四源顺序Solar137/NN5 111/PEMS04 307/AQShunyi11。
每源以SeedSequence([42,22,source_index,0])排列变量ID，取前8；每变量四模板10→1/12→12/14→7/48→24。
128拟合查询复用完整2264源验证清单；原生及alpha1逐八轨迹核验后复用，只新增alpha.25/.5。
另外128确认查询取源最后20%，同变量模板顺序如上，排除先前模板标签重叠，
以SeedSequence([42,22,source_index,variable,L,H,1])抽合法起点，历史及标签不能跨时间断点。
训练/验证原项目清单及诊断清单审计须证明未使用源末20%标签，不能证明则停止。
这只审计已记录项目谱系，不声称可审计官方预训练或未记录的计算。

先做门控留一源四折（基座适配器已经见过四源，不能把整个系统称为未见源模型）。
通过后全128拟合唯一门控，封存SHA，再只运行源确认原生和所选路径。
两道均要求变量内四模板MAE等权、变量/源内及四源等权几何平均S≤.99，任一源比值≤1.02。
近零epsilon沿用源训练段既定值；均近零比值1，不删除变量或模板。
源小样本分数不能替换完整源验证分数。失败结束，不修改规则再次尝试。

## 六目标和结果

仅两道通过后才访问目标预测结果。原Stage21每集128条固定清单、数据和哈希全部保留。
先封存全部768个alpha选择，再读取原生/alpha1旧预测；中间幅度新增生成。
每查询独立八采样种子和KV，逐步中位数；保存原始token、轨迹和所选幅度，原始缓存不覆盖。
主指标沿用变量等权原始单位MAE；六集均低于原生−max(1e−12,1e−9×原生MAE)才达目标。
原生回退持平不算改善。逐变量/逐步/微指标/覆盖/端点/回退以及门控幅度分布照实报告，不跨单位混合。
目标结果此前已看，属于开发重评而非独立盲测；无目标标签拟合不等于没有开发暴露。
新数据集直接用同一门控，不保证改善，不把小样本通过称为稳定普遍增益。
