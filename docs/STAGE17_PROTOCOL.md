## 架构与参数

复用已有官方 ChatTime-1-7B-Chat 权重 revision
`20baa88d6ab838b34abbd1d2b1f4cea57c8ff870`，官方源码固定
`8c2d4c209302d2b2bd6cc3c154586842341e3247`。不加载 Stage16 的连续预测头或图参数。
完整骨干和原语言头冻结；只让当前目标变量经过 LLM。辅助变量仅由共享轻量编码器和 GNN 编码。

```text
目标文本 → Transformer 1..30（冻结、无梯度、可缓存）
         → 图交互1 → Transformer31
         → 图交互2 → Transformer32 → 原始归一化/语言头 → 数值 token
辅助历史 → 共享因果卷积编码器 → GNN1 / GNN2 → 对应图交互
```

位置为零起始 `[30,31]`、`injection_side: before`、`prefix_layers: 30`。
两层 GNN、两个交互模块各自独立参数；各层内部跨节点、查询、源和数据集共享，无节点 ID 参数。
编码器为四通道历史、两层因果卷积、四段掩码均值/覆盖率、260→64 和 LayerNorm。
GNN 宽64；图交互 D/U 为4096↔64、Q/K为64→16、V为64→64，注意力缩放1/4。
物理先验消息与动态注意力消息各0.5；门控 sigmoid，门权重/偏置为0，U零初始化，额外残差缩放1。
完整公式按已批准方案实现于 `generative_graph.py`，没有回归输出旁路。

## 图、因果性与缓存

仅原始预测起点以前的 L 步构图及缩放；滚动教师强制只延长目标文本，不延长图历史。
缺失感知 Pearson、每接收节点 top8绝对相关、最低重叠 max(8,ceil(L/2))，并列按变量 ID；
权重为绝对相关乘重叠比例，边特征为带符号相关和重叠比例。
PEMS CSV 的 `from→to` 转为 `[receiver,sender]` 存储，保留方向；地理图为4近邻对称并集。
P、B 接收行归一化，屏蔽全缺失发送节点，空邻域消息为0，不产生无效 softmax。

冻结前30层缓存绑定权重、token、掩码、位置规则、提示边界、批次布局、精度及执行版本。
它可跨更新复用；图编码、GNN及后两层图条件 KV不可跨更新复用。
KV绑定参数版本、原始图身份和提示边界，加载参数、更新、换查询或滚动重建提示后失效。
实际 KV来自图修改后的隐状态。训练为完整教师强制，不复用图条件 KV。
无 Bolt / Stage16 文本 KV复用。RAM LRU≤32GiB；完整磁盘缓存的保守估算为256GiB，超过128GiB，故关闭磁盘缓存并按需计算。

BF16 默认库的完整与单 token 形状曾未通过既定验收。采用固定128行投影分块及按原始提示固定容量的
因果 SDPA 数值执行路径，保持权重、BF16精度、因果含义与实际 KV。
源原生基线和图模型采用同一执行路径；纯文本直接调用 native 时不进入该包装。
此选择可能增加计算开销；不把同执行路径的初始一致性称作所有默认库/内核的逐位一致性。
CPU FP32容差1e-6，真实BF16预测/梯度2e-3；保存状态精确恢复，未放宽验收。
正式真实权重CPU验收使用FP32；此前v1的额外CPU BF16验收出现初始化差异，已安全停止、
保留诊断，无GPU活动。该CPU BF16差异的底层原因尚未证实，不以CPU通过代替BF16 CUDA检查。
图交互仅对被选中的提示/回答位置逐token计算，固定完整前向与增量路径的FP32算术形状；公式及参数不变。
v2已完成真实FP32六历史验收，预测差0，梯度最大差2.98e-8，精确恢复通过。
v3仅修复监督器身份类型及跨恢复GPU UUID绑定，模型/数据/缓存模块字节、工厂和优化器/恢复函数AST不变。
v3严格核对旧证明的清单SHA、权重、数据、依赖、模块哈希和函数AST后复用真实模型证明，
并重跑当前完整CPU回归；复用来源在`cpu_preflight.json`明确记录，不假称重复运行真实模型。

每变量每模板一个固定源验证起点，共3396查询，禁止静默删变量或模板。
每查询最多监督16数值的回答块；提示/padding/缺失目标 token不计损失，先查询内平均再批次平均。

源原生 ChatTime 以相同 BF16、查询、贪心滚动解码计算一次完整基线；失败数值按固定最后观测回退，覆盖率另存。
选择先在变量内等权平均六模板原始 MAE，再除以原生误差，源内几何平均、四源等权几何平均。
近零 epsilon=max(1e-12,1e-6×max(训练段IQR,训练段Std))；分子分母均与epsilon取max。
双方近零为1；原生近零而图误差较大仍受惩罚。float64累计，保留逐变量误差和阈值。

AdamW lr2e-4、wd1e-4、clip1；前100更新线性warmup，之后恒定。
有效batch64，每源16；微4、累积16，OOM完整回滚后微2/1，顺序不变。
每250更新完整验证；每个严格更低的 S保存最佳，精确平分保留较早者。
相对早停参考改善≥0.1%才清零，否则计数加1；至少1000更新且连续5次无显著改善早停。
上限4000更新并完成对应验证，不能自动称充分收敛。只锁定源验证最佳 SHA，不运行目标任务。
