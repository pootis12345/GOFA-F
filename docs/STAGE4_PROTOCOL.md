## 学习率选择、训练与恢复

UFG-S/A 在 METR-LA、Electricity 各比较 lr=1e-3、3e-3，候选各 **200 更新**，共8组。
用户取消分钟时限后仍保留固定候选工作量，以保证可比性；不运行独立吞吐评测。
每种规模必须在两个关键数据集完成有效验证，按相对 Persistence 验证 MAE 比值的几何平均选 lr，
相对容差 1e-4 内取较小学习率。没有有效候选的规模不扩展，不用测试分数补选。
选中候选继续其原优化器、调度器、随机状态、采样位置和训练参数，不重新初始化。

UFG 使用 RMSprop、标准化缺失感知 MSE、weight decay=1e-4、
ReduceLROnPlateau（标准化验证 MSE，patience10）；最佳检查点和早停仍看 raw 验证 MAE。
GOFA 使用 AdamW、raw MAE、图 lr=1e-3、输出 lr=1e-4、weight decay=1e-4。
双方不同损失和原生优化器明确披露，不宣称优化过程或调参预算完全相同。
统一有效 batch64、最多100 epoch、patience15、梯度范数裁剪1。
复数梯度范数以两个实数分量共同计算；缺失标签按整个有效批量的有效目标数加权。

按10/30/100 epoch里程碑遍历所有正式组，先关键数据集，再其余四集，保持每组完整恢复状态。
里程碑不重置早停，不在同一更新点重复验证；里程碑验证均在 epoch 边界。
正式主表18组（六集×G2-V/UFG-S/UFG-A），加三个控制（两个 self、METR-LA clock）。
GNN 赢过 GOFA 不会阻止扩展。失败的版本如实标记，不自动换模型或追加架构搜索。

## 共享 GPU 与绝对截止

`scripts/run_pure_graph_stage.sh` 只启动纯 CPU 监督器。
连续3次、间隔30秒：无计算/图形进程、利用率0%、显存≤256MiB、Default模式，才入场。
查询失败或状态不明继续等待，不创建 CUDA 上下文。
每10秒监测，其他任务/未知状态/资源余量不足时对自建隔离进程组 TERM，最多60秒保存后只杀该组。
等待器自己重新等连续空闲条件，恢复不重置活动账本，也不延长绝对截止。

实际进程组显存上限40GiB、全卡至少余16GiB，通过 nvidia-smi 同时覆盖非 Torch 分配。
Torch 池进一步限制 UFG36GiB、Bolt38GiB，为 DGL 和驱动留余量；显存记录不只依赖 Torch 统计。
不修改计算模式、不终止其他用户进程、不更改其环境、不申请独占。
全局项目锁避免重复等待器，父进程失联时 worker 退出。

`launcher.json`：等待/运行/让出/完成/失败/墙钟截止；`active_budget.json` 继续记录完整 worker 活动秒数，
不再设置累计上限。`budget.json` 为逐任务成本记录。等待不计活动时间。
各模型族由同一 CPU 协调进程顺序启动，使用独立解释器、同一隔离进程组，绝不并发争抢 GPU。
