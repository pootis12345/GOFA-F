# Stage66：独立可变长度图专家与共享UFG

## 目标和边界

只用已审计四源训练一套独立图专家。L10—288、H1—144使用同一参数树和源最佳，不按数据集、节点ID或形状保存不同模型。先争取六目标宏MAE严格低于充分训练的共享UFG，同时报告原生ChatTime；结果不反馈本轮训练、源选模或配方。单种子点估计不宣称总体稳定优势。多种子、新时空分块及GOFA-F Memory融合仍是后续目标，不能用本阶段完成替代。

## 单一专家

184481个FP32训练参数。patch4、宽64、4头、3个时空块；不加载OpenCity/Moirai/ChatTime权重。每个实际节点保留完整历史分块和观测掩码，最后不足patch部分右补齐且显式掩码。节点先做有因果掩码的历史注意力，再沿真实接收行/发送列物理边读取0/1/2/4/8个历史patch滞后的信息；时间特征使用真实历史采样间隔及各patch实际结束时刻，包括不足patch的末尾。空邻域和全缺失辅助节点不产生NaN。

未来时距查询独立交叉注意历史；不使用h/H、未来查询间自注意力或未来缺失标记。输出为本节点最后有效值加本节点起点MinMax逆尺度乘共享连续残差，不裁剪预测。常数尺度取1，零与负值保留。物理输入只看起点以前。使用既有TAGLAS整层fringe3×10、最多31真实节点；不减少真实roster。抽样seed在固定L时不依赖请求H，并精确匹配原12→12/48→24输入；不同H的重叠预测需相符1e-6。

这是借鉴通用分块/时间查询和图注意力的组合新模型，不是Moirai或OpenCity原模型复现。气象/风电坐标四近邻图为代理关系，不能冒称直接测得的传输图。

## 多长度源清单

复用Stage59审核的PEMS04流量/速度、Boston2017和Penmanshiel2017的原始数据、节点划分和训练段单位归一化。交通两通道归同域。每视图8192训练查询，按ID/时间与seed42分层，合计32768；训练只用前60%标签和许可源训练节点。

训练长度固定10→1、12→12、48→24、96→48、192→96、288→144；形状等权，三领域等权，交通内部两视图等权。每查询全部真实节点有效未来槽先按节点平均、再按查询平均，原单位误差除源训练段persistence尺度。辅助未来只进入损失，不进入输入。

中间20%每视图/形状16条，384条完整源验证。先按变量等权MAE，再在视图/三域/长度等权几何聚合用于唯一选模；不混平均不同原单位。最后20%预封存320条源确认，覆盖六个训练形状与额外14→7、24→7、96→24、192→48；额外长度对不进入梯度或源选模。标签不跨时间划分/断点，源确认不用于返选。

## 等数据共享UFG

当前Stage65两主任务共享UFG健康运行，保持其旧固定快照和数据不变。新增多长度对照为从seed42全新训练的**一个**官方固定版本UFG核心，width128、canonical L48/H144、31个掩码角色，155607个有效参数元素/236144个实标量自由度。

保留FFT/framelet/k2/趋势核心；实际L步观测完整进入FFT，不补造/裁剪/重采样历史值。对同一48格参数做无参数历史分箱重叠积分与频率轴插值，所有H取同一144步头前缀。频域批图互相隔离。L48/H144输出及梯度与固定官方单查询执行相符1e-6；不是声称官方原实现支持任意长度。无形状专用参数、优化器或检查点。

专家与该UFG使用完全相同源查询、实际历史和全节点标签、batch32/微4、AdamW lr1e-3/wd0、warmup50、clip5。每500联合更新完整384源验证；上限40000，至少4000后连续8轮没有相对0.1%显著改善早停。严格最佳与显著改善参考分开。达到上限未满足早停须披露充分性未达到，不能宣称已收敛，也不能据此完成“充分训练共享UFG”目标。

## 运行、恢复和验收

CPU FP32，CUDA禁用，OMP/MKL/OpenBLAS各2线程；无活动或墙钟截止、不恢复周期自动通知。先运行专家，再运行新共享UFG，避免同时建立重复源缓存。逐更新保存模型、Adam、部分梯度、RNG、查询/领域/形状游标、源选模及累计活动。OOM只回滚当前未提交微事务并降微1，不丢节点或重置进度。科学结果失败原样封存；实现失败保留证据，禁止原样无限重启。

复用通用拟合器，只新增可选schedule_factory/summarizer参数，默认行为不变。旧任务使用旧固定快照，不受工作区新增代码影响。CPU单元/回归涵盖真实范围端点、非整patch、缺失/常数/空邻域、未来修改不影响输入、节点置换、批间隔离、参数树共享、H前缀一致及非零Adam/部分梯度逐位恢复。另用真实四源32条混合长度查询检查全部有效分支梯度和吞吐，并运行不复用到正式训练的两更新QA。

## 锁定后的目标评价

训练前封存Stage59固定六集各128主查询及每集每个额外长度对8条新查询，主768/补充192。补充查询只按ID、时间和合法缺失资格选，不依据误差。主查询的原生8采样记录和输入哈希只读复用，不新增7B预测；所有模型预测先逐条原子保存/封存，再统一读取真值评分。不存在目标训练、校准或返选入口。

报告主六集三组MAE/RMSE/MAPE/WAPE、逐变量/步、独立标量MAE回放1e-6、空间/时间分块区间及补充面板两模型指标。主六集宏MAE均严格低于UFG（容差max(1e-12,1e-9*UFG_MAE)）才记阶段点估计成功。补充面板逐格如实报告，不能用主任务胜利证明任意长度都更强。旧目标开发暴露、单种子、有限样本和代理图局限显式披露。
