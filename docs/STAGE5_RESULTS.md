## Electricity 验证诊断与路由

新模型验证 MAE 260.235，优于旧 G2-V 的 293.512 和 UFG-A 的 266.487。只以训练段标准差分组，验证段最高尺度 1/5 节点贡献 75.65% 的绝对误差；最高尺度的 17/321 节点贡献 54.33%。因此原始单位总 MAE 仍集中于少数大尺度节点。训练段对应比例为 74.10% 和可在 `diagnostics.json` 核对的最高 5% 节点记录。新模型第 1 至第 8 步验证 MAE 从 149.505 增至 320.746；零值目标验证 MAE 81.155（77,582 个位置），非零值 262.321。该数据没有历史缺失观测，不能从此组得出缺失鲁棒性结论。诊断只使用训练和验证段，未用于追加候选。

六集两层动态聚合平均占比介于 0.312–0.498；Electricity 的两层分别为 0.312 和 0.472。查询、键、路由和门控参数相对初始化均发生非零变化，说明新增分支参与学习；此统计无法单独归因性能提升。新架构同时调整动态图计算与 FP32 图精度，本轮没有消融，不能分别归因。

这些仍是单种子开发期结果。AQI-437 与 AQI-36 有重叠，旧阶段测试集已被查看；本轮结构和超参数在训练前固定，测试没有用于返选。HSD 属于限时参考，UFG 与 GOFA 的原生损失和优化器不同。约 21M 总参数匹配、语言交互保留以及单检查点跨数据集预测能力尚未验证。
