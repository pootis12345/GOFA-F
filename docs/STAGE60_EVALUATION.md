# Stage60 条件后接源确认与六目标公平评价

训练快照保持不变。本入口只接收当前Stage60源模型/共享融合锁，不训练参数。先等待Stage63对独立TSGFM路线的源检验：若它通过匹配外推，则本入口停止推进，先完成新专家的Memory集成；若其科学门槛失败，才等待当前Memory候选完成源选模。实现故障不当作科学失败，不以目标成绩决定路线。

## 充分UFG与源确认

主源监督器和worker均实际退出、adapter/共享gate锁定后，组合Stage62充分UFG对照：短形状10500最佳/12500早停、长形状3500最佳/5500早停。逐一绑定来源数据/训练及开发查询/归一化/采样/检查点SHA与两分支源早停证明。旧Stage60快照中的有限预算UFG副本不编辑；新的部署清单明确引用充分对照。原生、增强流、最终融合和UFG四组全部报告，不预设排序。

使用Stage60训练前已封存的256条新源确认，只报告，不重选模型。全部预测/8条Native轨迹原子保存并校验绑定，恢复仅补缺失。四组完成、模型/梯度未变、GPU和CPU进程退出后才开放未来真值评分和确认完成证明。源确认不作为返训或另选第二模型的依据。

## 六目标

只有源确认完成后才准备六目标。保留Stage21原六集各128条的变量身份/配额及12→12、48→24形状，用seed60按合法时间/缺失资格选择新起点，排除Stage21和Stage59已看同变量标签窗口及本轮已选窗口，不读预测误差。新窗口不能抹去历史目标开发暴露，不称独立盲测。真值不进入图、辅助历史、尺度、Memory、提示或生成输入。

保持保护原生官方提示/尺度/语言头及8独立采样逐步中位数；增强流和融合为连续派生预测，不另计语言生成覆盖率。三跳整跳10候选的真实节点不截短，辅助节点不做自回归生成。调用原已验收数值/采样/指标实现；新GPU worker仍须原四源Native token精确重放、新查询完整/共享前缀/增量预测一致及冻结证明。CPU1e-6、CUDA BF16 2e-3且采样token一致，不放宽。

资源memory_cap_only，项目40GiB/Torch38GiB、10秒审计，无截止时间。等待源锁期间是CPU控制器，无新CUDA上下文。不得重复启动健康任务；失败保留证据，不能盲重启。评分或CPU导出恢复不再加载已完成GPU预测。

## 汇总交付

四组全部完成并退出后，沿用变量等权有效点原单位MAE、RMSE、MAPE阈值|y|>1e-5/WAPE零分母规则、逐变量/步、配对改善及2000次空间/时间分块区间。六集融合MAE逐一严格低于Native和充分UFG（max(1e-12,1e-9×基线)）才判精度门槛通过。

导出前重新校验全部8轨迹、中位数和四组记录，并用独立标量求和复算MAE。交付模型/配置SHA、真实节点/采样/文本清单、源确认、四组源/目标指标CSV和完整成本。加入四组CPU时间专家初始化、TSGFM独立尝试、充分UFG续训及当前联合拟合曲线。UFG旧祖先CPU只计一次，新增充分性训练另列；控制器等待不冒充GPU活动/训练核秒。联合最佳0若被保留，指已训练的时间专家初始化，不等于未训练或持久性；非零Memory读出不自动证明图贡献。
