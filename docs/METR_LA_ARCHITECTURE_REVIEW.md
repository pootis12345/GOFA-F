# METR-LA 结果与图上下文修订

核对日期：2026-10-14。本轮改动仅在开发仓库；正在运行的 `stage2-native-v1`
仍固定于 `3c31da6`，不含这里的新信息通路。改进版尚未启动训练，没有精度提升结论。

## 已实现的信息通路

Bolt 对每个节点、每个窗口做 instance normalization。原图模块只交换归一化后的隐藏表示，
节点的 loc/scale 留到各自输出反归一化才使用，因而邻居的绝对水平可能在交换前就被消除。
这是一项具体的表达能力限制，不能据此认定它解释了全部精度差距。

新图模块使用共享投影，将以下 11 维窗口/节点信息加入消息聚合前的低秩表示：

|信息|计算方式|
|---|---|
|水平|窗口内已观测值的均值|
|尺度|窗口内已观测值标准差的 `log1p`|
|最近值、趋势、覆盖率|最后一个已观测值、缺失感知线性趋势、已观测比例|
|已知时间|预测起点的日内/周内周期正余弦，以及日/周时间可用标志|

先撤销逐节点训练段标准化、恢复共同物理单位，再用整个数据集已观测训练段的 pooled mean/std
对齐水平和尺度。不能直接将各节点独立标准化后的均值相互比较。
趋势只用输入历史，统计量仅拟合训练段；时间只取预先可知的源时间戳，未来观测不进入特征。
图投影在全部节点之间共享，不引入与节点数量绑定的 ID 参数表。

交通和 AQI 的时间戳从原 HDF 恢复，并核对源文件哈希、完整时间序列值和行对应关系；
能源原始矩阵不含可信时间戳，因此时间相位及可用标志均为零，不猜测起始日期或星期。
独立侧文件位于 `data/features/context-v1/`，原始数据和准备后的 NPZ 均未覆盖。
后续对照中，HSDGNN 也使用可用的源时钟；能源仍明确记录样本索引周期回退，不能称为真实星期。

两个 rank=64 图模块各增加 `11*64=704` 个参数，合计 **1,408**。
GOFA-F(Bolt) 总参数 **21,337,346**，可训练参数 **101,250**；原生骨干及输出头仍冻结。
上下文投影零初始化，已有图权重加载后能保留原预测；图门控为零时仍与原生 Bolt 一致。
冻结前缀缓存内容不变，侧信息在图模块处注入，不缓存可训练信息。

新配置为 `configs/next_stage_context.yaml`，继承既有配对长度、种子 42、预算和共享 GPU 限制。
使用独立机制报告，启动前绑定完整展开配置；断点 manifest 额外绑定时间侧文件、元数据及输入数据哈希。
原默认配置不启用上下文。不能将旧阶段的检查点称为新结构的完整优化器恢复。

## 已完成验证与边界

C 上禁用 CUDA，Ruff、shell 语法检查和 **81 项 CPU 测试**通过（pytest 3.33 秒）。
新增检查覆盖物理单位对齐、缺失、时间可用性、未来标签隔离、邻居信息通路、
已有非零图权重兼容、两种插入位置的缓存预测/梯度一致、冻结骨干无梯度、
HSDGNN 源时钟/未知回退，以及续训输入指纹变化。
六个真实数据集均完成侧文件准备及 CPU 特征组装检查。

使用真实 Bolt-mini 权重和已完成的 METR-LA 图权重做三节点 CPU 检查：
零上下文投影与旧图预测最大差为 **0**；故意设置非零上下文投影后，改变邻居水平或已知时间
能够改变目标节点预测，反向梯度有限。该检查使用合成输入，投影没有通过训练获得，
它只验证通路容量和兼容性，不是精度、收敛或吞吐结果。
记录在 C 的 `outputs/native-context-cpu-check.json`；它不替代新阶段所需的真实 BF16/GPU 前置检查。

## 对当前架构的借鉴

- **STAEformer：补充时间条件，并让时间与空间表示交互。** 论文使用日内、星期与自适应时空嵌入。
  当前先实现廉价的共享时间投影；其与固定节点集合绑定的自适应参数表不应直接照搬到跨数据集版本。
  这支持本轮修改的设计动机，不能代替 GOFA-F 的消融证据。
- **Graph WaveNet：物理图与自适应图共同使用。** 可在已有道路图上保留正向、反向消息支路，
  再添加小型内容驱动图分支，保留残差。学习图作为补充，不丢弃物理先验。
  其扩张时序卷积也提示短历史局部时间建模值得检查，但不宜同时更换骨干和图模块。
- **MTGNN：保留方向性、稀疏关系和多跳信息。** 可用共享节点上下文生成 Q/K，进行 top-k 图学习，
  在有限邻域内引入一至两跳残差。避免用固定节点 ID 表定义全部关系；长步训练课程可作为单独消融。
- **MegaCRN：从历史状态查询共享原型，调节图消息。** 可用小型共享记忆库表征畅通、拥堵等状态，
  不需要复制大型骨干。迁移版必须用内容查询，而非依赖某个数据集固定节点索引。
- **TESTAM：根据状态选择自身、静态图、动态图信息。** 可在单个冻结 Bolt 上增加轻量消息支路及门控，
  让孤立节点或突发事件时降低无效邻居信息；不直接复制三个 Transformer 专家，控制训练成本。
- **STEP：预训练表示辅助图学习。** 该工作在 METR-LA 实际使用一周历史：168 个 patch × 12 步 = 2016 步，
  预测 12 步；两周历史用于 PEMS04。它的 3.37 不能当作严格 12→12 信息预算下的结果。
  可以借鉴冻结表示复用，但不能通过缓存悄悄引入当前历史长度之外的观测。

## 少量输出端适配：下一项独立消融

先验证本轮上下文，再考虑零初始化的低秩输出增量。最小候选是在原生输出头最后一个
`1536→576` 线性投影外叠加 rank=4 的 `BA`：新增 **8,448** 个参数。
如果验证集仍显示输出约束明显，再考虑输出 ResidualBlock 三个线性层都加 rank=4，
总增量 **19,968** 个参数。两者都是待验证设计，当前尚未实现或训练。

适配权重应作为 GOFA-F 私有的外部增量，不能原地修改与 native baseline 共享的输出头；
需保持分位数输出的对应关系，并记录可能的分位数交叉风险。
小参数量不保证精度或时间收益。输出适配不解冻骨干，也不自动赋予 Bolt 语言交互能力。

建议验证顺序：原图 → 加水平/尺度等统计 → 再加已知时间 → 最后加少量输出适配。
使用同一 seed、插入位置、数据划分与训练步数隔离改动；按验证集选择，最终才评价测试集。
优先 METR-LA 验证机制是否有益，再决定六数据集消融范围；不要与当前阶段并行启动重复训练，
不要自动增加已授权 8 小时之外的 GPU 预算。
