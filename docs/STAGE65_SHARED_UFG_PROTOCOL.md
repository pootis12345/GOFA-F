# Stage65：单一共享参数UFG，重新源训练与六目标评价

用户明确取消按形状使用两个UFG模型。旧Stage59/62/64数据与结果完整保留，但旧两形状权重不再是本目标允许的对照；禁止把同文件夹中的两套参数包装为“一个检查点”。Stage60旧后接评测协调器已合作停止，主GOFA-F源训练不变。其主评测必须在后续改用本共享UFG，不能继续据旧对照判断本目标完成。

## 单模型适配

只创建一个官方固定版本UFG核心（width128、31角色、Haar/二阶近似/一层framelet/k2），全部形状共用频域卷积、趋势分支和24步输出头。所有源及目标共用同一state_dict、模型SHA与一次源选模；从seed42全新初始化，不加载或拼接旧两形状权重。

实际12或48步历史完整进入FFT，不截短、不补造历史，也不重采样输入值。因原官方参数含固定长度的频率滤波器、复数频率投影及历史线性投影，在同一组48步基准参数上作固定无参数映射：频率轴线性/双线性重采样（不混通道）；历史轴按固定12/48分箱积分共享权重，保留常数响应。FFT长度仍为原max(16,L)。输出头始终24步，12步任务只计算前12步监督/评分，绝无分形状训练头或检查点。

这是共享长度UFG适配，不冒称官方原模型支持任意长度。48→24、单查询的输出/梯度必须与固定官方执行相符1e-6。额外核验同一参数在两种形状切换不变、完整历史/缺失/全节点梯度、保存加载及部分优化器恢复。

批训练每个查询独立构建频域kNN图，防止不同起点的历史经批内边交换；DGL三维批图形成互不相连的分量。同一查询单独/批内，以及修改其他查询历史时，该查询预测必须相符1e-6。保持所有真实采样节点与31虚拟角色标记原规则。

## 训练与封存

只读复用Stage59已审计四源32768训练/256开发查询、同历史节点及有效全节点标签资格、缺失规则和训练段单位归一化。交通两视图作为同领域；既有来源/形状循环实现三领域等权、流量速度等权、两形状等权。每批64混合查询，按形状仅分组做尺寸计算，梯度累计到同一优化器。

AdamW(weight_decay0，即同固定Adam更新)、lr1e-3、clip5、无额外warmup、seed42。每500联合更新完整验证256条，源选模与0.1%早停参考分开；至少4000更新后连续8次无显著改善停止，上限40000。相对旧每形状batch64、250验证/至少2000/20000上限，本轮每形状每联合更新约半批，按等查询暴露量加倍联合更新间隔与上限，不用削减预算促成期望排名。触顶未满足早停须披露充分性标准未达，不声称收敛。

逐更新保存同一模型/优化器/部分梯度/RNG/来源与形状游标/选模/累计活动。实现失败保留证据、核实退出后新固定版本修复，不盲重启；全部旧结果不覆盖。CPU禁CUDA、OMP/MKL2，无墙钟或活动硬截止。
