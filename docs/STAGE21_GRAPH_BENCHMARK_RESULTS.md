## 诊断

1. 交通迁移较有利，但收益分布不同。PeMS03改善79/128查询；BAY仅65/128改善，63退化。
   BAY前5条改善查询占全部正向加权改善量的81.33%（在扣除退化前统计），不能解读成81%的查询改善。
   BAY微RMSE由7.6013降至4.6797，说明部分大误差减少；仍不能承诺逐节点普遍受益。
2. 气象未获得一致增益。MeteoNet平均接近持平；EngRAD的MAE退化11.68%。
   EngRAD首步MAE 0.6863→0.6365（−7.24%），第2–16步2.1637→2.4253（+12.09%），
   第17–24步2.1107→2.3566（+11.65%）。问题不只出现在第17步以后；与多步前缀/迁移偏差相容，不能仅凭该模式证明根因。
3. 风电收益较小。两集MAE约改善2.9%，但不能称所有指标改善；低功率及接近0°C使MAPE很不稳定。
   SDWPF微MAPE反而3852.14%→4204.25%；主结论遵循预注册变量等权MAE。
4. 没有执行故障或非法生成掩盖。所有模型格式完成、反变换有效均100%，回退0；受约束格式完成不代表精度。
   气象两集整段恒值中位数预测均0，不支持将其退化归因于重复一个数值。
   SDWPF整段恒值预测原生32/128、图模型25/128；其中真值仍变化的分别19/128、14/128，剩余恒值问题未消除。
5. 固定尺度仍有表达范围限制。真值超过词表可表示区间比例：PeMS03 13.54%、BAY 11.72%、
   MeteoNet 4.31%、EngRAD 1.46%、SDWPF 10.04%、Kelmarsh 4.75%。这些不是回退率；范围下界和逐查询证据见JSON。
   两模型共享尺度，范围限制不能单独解释它们之间的全部差异。

以上只支持固定图增强系统在部分任务的迁移收益。未增加自环、打乱图等消融，无法把收益独立归因于真实图结构。
没有新增GPU干预，不根据六集测试返调检查点、图系数、采样或模型，不据此自动恢复训练或改用数值头。
