# Stage63：条件推进的同来源分组外推

这是Stage61事先规定的下一步，不增加模型、超参数或源数据。纯CPU两线程，无新GPU、ChatTime加载、Memory联合训练或目标读取入口。先等待并核验Stage61/62真实进程退出；不会把准备/锁文件当作模型完成，不重复启动健康任务，不盲重启失败。

## 先核对充分对照，再决定是否训练

Stage61原全源开发筛查必须通过，否则新训练为0并封存。之后Stage62两形状都必须满足原UFG源早停条件，不能把新20000上限当作收敛。读取两组锁定权重对应的源开发原始预测，逐条复核源query、模型张量SHA、历史输入、真值和缺失掩码；与独立TSGFM锁定最佳的相同256条源开发记录重新聚合比较。只有各领域专家/UFG比值≤1.02且三领域等权几何平均≤0.99才继续。两步仍是见过相应来源训练标签的开发筛查，不称零样本胜出。

## 真正匹配的源外推

固定留交通、留气象、留风电三组；PEMS04 flow/speed必须一起留出。每组双方都从seed42全新初始化，绝不加载包含留出源标签的全源权重。训练/检查点选择仅用其余来源，封存最佳后才开放该组源开发查询预测。双方使用同一个只读源历史/实际节点/有效全节点标签缓存，未来值只参与监督损失，不进入输入。TSGFM共享两形状一套权重、UFG按原官方两形状权重分别训练，明确披露。

固定每组一个TSGFM（Stage61相同配方，上限10000）与两形状官方width128 UFG（原batch64/lr1e-3/clip5/每250验证，上限20000）。各自沿用0.1%参考、至少2000及连续8轮不显著改善的早停；没有搜索或按目标成绩延长预算。UFG各组若先触顶，报告其充分性标准未满足，不能据此声称强于充分UFG。所有源拟合的优化器、部分梯度、RNG、来源采样游标、选模、预测分片、成本均独立保存。只有同一绑定的合作暂停可以精确接续；实现故障须审计，不能无限原样重启。

三组共256条源外推查询，两个模型逐条query/输入/真值/掩码完全相同，另与源缓存独立核对，再按变量有效点MAE、视图比值与三领域等权几何平均汇总。推进门槛仍是每领域≤1.02、几何平均≤0.99，且UFG各拟合满足源早停。全部记录如实保留；失败不删除来源、不强制图权重、不换候选。通过也只支持这些源组之间的迁移，不等于六目标全胜或已证明真实图贡献。
