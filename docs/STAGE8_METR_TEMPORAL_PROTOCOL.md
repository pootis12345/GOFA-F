# Stage8 METR-LA 12→12：细粒度历史图上下文

本轮只训练 METR-LA、seed 42。两候选均从同一个冻结的 Bolt-mini 预训练权重初始化，使用物理距离图、六维已知源时钟、`late_contiguous [1,2]` 图交织、rank16 动态路由、至少 0.5 的物理图先验聚合及私有 rank4 输出适配。骨干输入 patch 为16，而历史仅12步；新增图上下文不改变原生输入或添加输出旁路。

- T1（`t1_sketch`）：把12步历史按顺序切为四段，每段计算历史观测均值和有效比例，形成8维特征。均值恢复节点的训练段标准化后，再按训练前缀观测值的总体均值和尺度表示；全缺失段置零。与原有11维节点水平、尺度、趋势、覆盖率和已知时钟特征拼成19维，送入两个层间图模块。只读取预测起点之前的历史。
- T2（`t2_correlated`）：保留 T1 的全部结构与参数形状。另以训练前缀的有效观测对计算绝对 Pearson 相关，逐节点 top-8 后对称化。动态注意力在物理边和相关边的并集上分配；物理先验聚合仍只使用原物理图。图侧文件、SHA、物理边数及新增有向边数写入输出和恢复清单，不用验证或测试值构图。

训练为原始单位缺失感知 MAE、AdamW、图和路由学习率 `1e-3`、输出适配 `1e-4`、weight decay `1e-4`、梯度裁剪1，有效 batch64，最多100 epoch，patience15。两候选使用相同 seed 和逐 epoch 采样顺序；保存模型、优化器、随机状态、游标与活动账本。验证集完整12步原始 MAE ≤3.12565 且第12步 MAE ≤3.79606 才合格。合格者按全步 MAE 选；两者差距低于0.5% 时选 T1。仅对锁定 SHA 后的获选合格候选评测测试集；未合格不测试，也不添加候选。

新配置为 `configs/stage8_metr_temporal.yaml`，入口为 `scripts/run_metr_temporal_stage.sh`，固定快照与输出名为 `stage8-metr-temporal-v1`。首次启动 CPU 等待器时绑定12小时墙钟截止和提前15分钟的训练截止；等待也计入窗口，恢复不顺延。每个新的 GPU 子任务须连续三次、间隔30秒核实无计算/图形进程、利用率0、已用显存≤256MiB、Default 模式才准入。运行中他人加入不退出；余量不足时暂停更新。项目进程上限40 GiB，Torch38 GiB，保留至少16 GiB，不设置独占模式或操作他人进程。

C 上禁用 CUDA、OMP/MKL 各两线程的 CPU 回归覆盖时间因果性、全缺失、训练前缀相关图、初始原生预测、缓存预测与梯度、冻结骨干、验证门槛和准确恢复。GPU BF16 机制检查同样经严格空闲准入，失败即停止，不放宽容差。阶段结果应包含两候选验证指标、选中者测试全步与逐步误差、参数、更新数、停止原因、活动时间、显存峰值和未完成项。

TITAN 报告的第12步 MAE 3.08 只作跨实现外部参照。现有数据划分、原图和掩码协议不因该数值改变；TITAN 的完整公开模型与评价实现尚无法核对。仅单种子，且既往开发阶段已查看测试集，本阶段不宣称严格复现或稳健超越。
