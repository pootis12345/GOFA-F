# Stage60：仅源数据的分阶段专家初始化与联合训练

## 依据与边界

Stage59全源拟合完成500更新/4000查询后早停，最佳是输出严格持久性的更新0；三轮留气象、留风电及六轮留气象也保留初始参考。优化器确有450/500步、主要分支有限变化，不能认定没有执行训练。此处仅依据源训练记录改进初始化和训练覆盖，不使用Stage59六目标的误差、排序或逐查询记录来制定新方案。

唯一固定改动是先训练**现有**GRU与连续头，再接回原专用Memory双向交织。没有新增目标监督、数据、SCADA、预测分支、按集参数、词表或提示规则；Native与UFG均不削弱。三跳整跳10候选/最多31真实节点、主六轮/候选三轮、所有节点共享冻结ChatTime保持不变。本阶段仍以六目标同时超过Native和充分UFG为最终目标，CPU初始化通过不是目标完成。

## CPU初始化（先运行）

沿用Stage59已封存32768条训练查询、256条源开发查询及完全相同的序列化真实节点/有效全节点未来槽。源开发已暴露，照实披露。所有训练查询池从第一轮即全部启用、变量/时间优先序和确定性打乱沿用既有实现，不从小池逐渐扩展。仅使用前60%训练标签；源开发用于同一来源内选模。

模型只包含生产接口中同形状的GRU(3→128)及连续头，4×128维Memory读出输入固定为0。头第一层对应Memory的列保持严格0，最后层仍从0初始化；原始完整历史、观测掩码和相对时间进入GRU，输出仍为最后观测加起点尺度乘共享连续残差。原单位有效槽→节点→查询归约和训练段单位归一化沿用Stage59，不改变损失。

固定AdamW lr1e-3、wd1e-4、clip1、batch/micro16、warmup50，最多2000更新；每100更新完整验证，至少1000更新，独立0.1%参考、连续8轮无显著改善早停，严格最低分保存。先拟合全源；若最佳仍是更新0，保存结果并停止本方案的GPU推进，不强制选非零检查点。通过后完成留交通/气象/风电三组拟合；交通流量和速度始终一起留出。四组初始化分别封存，两个交织深度只可共享同一纳入来源的初始化，不跨留出组泄漏。

复用现有逐更新模型/优化器/梯度/RNG/游标保存及事务恢复。CUDA显式禁用，OMP/MKL各2线程。源缓存只读复用，旧结果不编辑，CPU驻留和GPU继承成本分别记录；从已封存成本文件继承27019.525957秒（包含源训练及后续确认/目标评测），不只继承父源目录中的22427.093508秒。首个未训练准备版本漏列后续评测继承成本，保留其清单证据，正式使用修正的`stage60-source-warmup-v2`，没有模型训练或预测需要迁移。

## 接回Memory后的正式流程

将对应来源组的GRU/头初始化加载到全新Memory接口，必须在创建联合优化器及任何存活计算图之前完成。其他Memory/图参数按seed42重新初始化，不导入旧目标训练适配器。任意Memory下，加载后预测须与CPU初始化预测一致；验证CPU FP32 1e-6，不放宽。Memory列初始为0并不作为最终保持条件，后续联合训练可更新全部原有接口/图参数。

保持原六轮/三轮分组外推选深度、一次新全源拟合及源交叉拟合共享门控流程。联合训练固定AdamW1e-4、wd1e-4、clip1、batch8/micro1、warmup50、前50更新冻结图交换；每100完整源验证，至少1200更新、连续8轮无0.1%显著改善早停，最多3000更新。全训练池从起点启用。初始化来源最佳纳入更新0比较，若最终仍选择该参考须明确披露Memory学习未获保留；不能冒称图收益。

不在CPU初始化结果后调整学习率、容量、损失、门槛或增加候选。复用未变数值核证明；加载新初始化后必要的非零更新/完整与缓存梯度、完整与增量Native及采样一致性检查仍执行。资源保持memory_cap_only、40GiB项目/38GiB Torch、10秒审计，不设时间截止，不截短已锁定子图。

## 隔离、确认与评价

拟合前封存256条新源确认查询，排除Stage59和其继承旧源开发/确认/诊断预留窗口；只按ID、时间和缺失资格选择，不读取误差。CPU初始化、联合拟合和门控不得读取这些标签。唯一部署锁定后才源确认，随后封存六目标各128条新时间查询再作一次公平评价；旧目标结果不返选。

Native源开发预测及充分训练UFG只在数据/真实节点/提示/采样/权重/核绑定相同且来源完整记录后复用，不重训以追求排名。六目标Native/增强/融合/UFG真实排名和不确定性全部报告，严格双基线门槛不变。代码、初始化或源改善不构成六目标成功。

本轮源训练入口先交付CPU初始化及其精确迁移；后续联合运行必须绑定这四组封存SHA，不能把CPU就绪状态报告为完整联合训练或目标完成。无自动跟进恢复。
